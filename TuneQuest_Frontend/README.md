# TuneQuest Frontend

This is the React frontend for TuneQuest, a personalized music learning platform powered by AI. It features adaptive practice plans, AI-generated quizzes, and interactive song performance tutorials.

## ✨ Features

- **Authentication**: JWT-based login/register with error toasts
- **AI Practice Plans**: Personalized daily exercise plans generated by Claude AI
- **AI Quizzes**: Dynamic quiz generation with immediate feedback
- **Song Learning**: Interactive song performance tutorials with visual timelines
- **User Profiles**: Customize instrument, skill level, and learning goals
- **Progress Tracking**: Visual progress bars and practice statistics
- **Account Management**: Profile updates, subscription management, account deletion
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Dark/Light Theme**: Toggle between themes with persistent selection
- **Background Effects**: Animated backgrounds for enhanced UX


### 2. Create `.env` file



## 🔄 State Management (Redux)

### Auth Slice
```js
{
  token,           // JWT access token
  user,            // { id, email, username, ... }
  subscription,    // 'free' or 'premium'
  error,
  isLoading
}
```

### Profile Slice
```js
{
  instrument,      // 'Guitar', 'Piano', etc.
  skillLevel,      // 'Beginner', 'Intermediate'
  goal             // Learning goal
}
```

### AI Plan Slice
```js
{
  plan,            // Full practice plan object
  exercises,       // Adapted for ExercisesPage
  quizzes,         // User's AI quizzes
  songCache,       // Cache: { [stepId]: { songTitle, songPayload } }
  quizCache,       // Cache: { [stepId]: { quizData, quizObject } }
  tokensRemaining, // AI token balance
  skillLevel,      // From plan form
  instrument,      // From plan form
  dailyPlanId      // Used for backend updates
}
```

## 🔐 Authentication Flow

1. **Login**: POST `/api/auth/login/` → get tokens
2. **Store**: Save tokens in localStorage and Redux
3. **Requests**: Include `Authorization: Bearer {token}` header
4. **Refresh**: Auto-refresh at midnight PT via `tokenRefresher` service
5. **Logout**: Clear all Redux state, localStorage, and sessionStorage

## 🚀 Development

### Adding a New Page
1. Create file in `src/screens/PageName.jsx`
2. Create CSS module `src/styles/screens/PageName.module.css`
3. Add route in `App.js`
4. Import in `App.js`

### Adding API Endpoint
1. Add function in `src/services/api.js`
2. Use in component via `import { apiFunction } from '../services/api'`
3. Call in useEffect or event handler

### Common Patterns

**Fetch data on mount:**
```js
useEffect(() => {
  if (!token) return;
  api.get('/api/endpoint/')
    .then(res => dispatch(updateState(res.data)))
    .catch(err => console.error(err));
}, [token]);
```

**Handle form submission:**
```js
const handleSubmit = async (e) => {
  e.preventDefault();
  try {
    const res = await api.post('/api/endpoint/', formData);
    // Success
  } catch (err) {
    setError(err.response?.data?.detail || 'Error');
  }
};
```
